Kebijakan Privasi

Berlaku sejak 11 November 2026

1. Siapa kami

"Trend Error" adalah aplikasi pribadi studio TREND ERROR. Aplikasi ini dipakai pemiliknya untuk mengelola akun media sosial miliknya sendiri.

2. Data yang kami akses

Saat pemilik menghubungkan akunnya, aplikasi hanya menerima data yang diizinkan pemilik pada layar persetujuan resmi tiap platform:

  • YouTube (Google): profil dan daftar video kanal, izin mengunggah dan mengelola video, komentar, serta analitik kanal.
  • TikTok: profil dasar, statistik akun, daftar video publik, dan izin mengunggah video.
  • Instagram dan Facebook (Meta): profil akun Instagram profesional, Halaman Facebook yang tertaut, izin menerbitkan konten, komentar, pesan, dan insight.
  • Threads: profil dasar, izin menerbitkan, balasan, dan insight.

Aplikasi tidak mengumpulkan data pengguna lain di luar akun milik pemilik.

3. Bagaimana data dipakai

Data dipakai hanya untuk menampilkan akun yang terhubung, mengunggah video yang sudah disetujui pemilik, membalas komentar atas persetujuan pemilik, dan melihat performa konten. Data tidak dijual, tidak dibagikan kepada pihak ketiga, dan tidak dipakai untuk iklan.

4. Penyimpanan dan keamanan

Token akses disimpan terenkripsi di server milik pengelola dan hanya dapat diakses pemilik. Tidak ada kata sandi platform yang disimpan.

5. Hak Anda

Pemilik akun dapat mencabut akses kapan saja melalui pengaturan keamanan tiap platform (misalnya Google "Aplikasi pihak ketiga", TikTok "Aplikasi dan izin", Meta "Integrasi bisnis") atau dengan memutus akun di aplikasi. Setelah diputus, token dihapus. Untuk meminta penghapusan data, hubungi ai.liveofficedav@gmail.com.

6. Data Google

Penggunaan informasi yang diterima dari Google API mematuhi Kebijakan Data Pengguna Layanan API Google, termasuk persyaratan Penggunaan Terbatas.

7. Perubahan

Kebijakan ini dapat diperbarui, dan versi terbaru selalu tersedia di halaman ini.
